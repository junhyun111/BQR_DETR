# BQR-DN V2

This package enriches only the training-time DINO denoising-query content with
features sampled around DINO's noisy box references. The official DINO
backbone, encoder, two-stage matching queries, decoder, heads, attention mask,
Hungarian matching and DN reconstruction criterion remain shared.

The importable Python package is `dqr_v2`; the enclosing directory keeps the
requested experiment name `dqr-v2`.
